# Contributions and issue reports

Please use GitHub Issues for reproducibility problems. Include the archive version/hash, command, Python/PyTorch/CUDA versions, GPU, relevant dataset layout and a short error trace. Do not post credentials or dataset contents.

The historical source is preserved to identify the implementation associated with the reported results. Proposed fixes should use a separate branch and describe their behavior change. A fix must not be presented as the code that generated the old results unless that relationship is independently established. Any new measurements should identify their protocol and code revision.

Preserve third-party notices. New original contributions are submitted under the repository's BSD-3-Clause license unless a file explicitly states otherwise.
